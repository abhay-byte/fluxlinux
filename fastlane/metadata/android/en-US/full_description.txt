FluxLinux Pro brings full Linux desktops to Android. Install Debian with XFCE4, run dev tools, and use GPU acceleration.

<b>Features:</b>
• One-tap Debian install
• GPU acceleration (Turnip/VirGL)
• Web, App, and Data Science stacks
• XFCE4 desktop with themes
• Rooted & Non-rooted support

<b>Requirements:</b> Termux (from F-Droid) and Termux:X11 (from F-Droid). Both are free.

FluxLinux Pro does not collect any personal data and does not transmit data off-device.
