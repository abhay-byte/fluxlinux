FluxLinux brings full Linux desktops to Android. Install a guest distro, run XFCE, and use GPU acceleration — no external Termux app required.

<b>Features:</b>
• Embedded host terminal and X11 display
• Twelve distros (Debian, Alpine, Fedora, Ubuntu, Arch, and more)
• GPU acceleration (Turnip/VirGL)
• Host PulseAudio for guest sound
• Web, App, and Data Science stacks
• XFCE desktop with themes
• Rooted (chroot) and non-rooted (proot) support

<b>Note:</b> Distro rootfs archives download from GitHub after an in-app opt-in. No data is collected.
